# AI-Based Exam Cheating Detection System

AI-Based Exam Cheating Detection System is an intelligent online exam monitoring prototype developed using Python, OpenCV, and MediaPipe. The system uses Computer Vision and AI reasoning algorithms to analyze student behavior during online examinations.

## Features
- Face Detection
- Eye Tracking
- Looking Away Detection
- Suspicious Behavior Alerts
- Screenshot Capture System
- Rule-Based Reasoning

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Project Structure

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Project
python main.py
